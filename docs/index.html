Features

Clipboard history,
kept simple.

Pastel runs in the tray and provides quick access to recent clipboard items.

⌕

Search clipboard history

Type when Pastel opens to search clips, or filter the list by content type.

⌕Search “launch plan”3 results
◇

More than text

Keep images, formatted text, links, code, colors, files, and folders—not just plain text.

⌁

Keyboard navigation

Use arrows and Enter, or select a visible card with Ctrl+1–9.

⌖

Pinned clips

Keep frequently used addresses, snippets, commands, and other items available.

▱

Windows integration

Rounded corners, acrylic materials, tray controls, optional startup, and a Windows installer.

◎

Local storage

No account or cloud service is required. Clipboard history is stored in local app data.

How it works

Copy. Find. Paste.

Pastel runs in the system tray and opens with a global shortcut.

  1. 01

    Copy naturally

    Pastel captures supported clipboard content in the background.

  2. 02

    Press Ctrl + Alt + V

    Your visual clipboard history opens over the app you’re using.

  3. 03

    Choose and continue

    Search, select, and paste directly back into your previous window.
